# Arthur Gomides: portfolio

Static portfolio site for Arthur Gomides, content video editor.

- `index.html` — English
- `pt/index.html` — Portuguese
- `styles.css`, `site.js` — shared styles and behavior
- `media/` — showreel, work excerpts, posters and photo

No build step is needed to publish: serve the folder as is (GitHub Pages, Netlify, Cloudflare Pages).
`build/` holds the generator used to produce the two HTML pages from `build/data.json`.
